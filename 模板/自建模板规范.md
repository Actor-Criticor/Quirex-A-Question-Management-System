# 自建讲义模板 · 规范与接口

这份文档讲**模板目录里的东西**：一套模板由哪些文件组成、`meta.json` 每个字段是什么意思、
程序会往 `{{...}}` 里塞什么、哪些写法会被判成"不可用"。
（想学怎么用这个系统，看根目录的 `README.md` 和 `系统说明.md`；这份只管模板。）

一句话概括设计：**模板自我描述，导出程序只按描述办事** ——
加一套模板 = 往模板目录里放一个文件夹，不碰任何代码、不用重启。

---

## 模板目录在哪

- **默认位置**：根目录下的 `模板/`（跟 `代码`、`题库`、`导出` 并排）。
- **改位置**：「设置 → 路径 → 模板目录」。改完**立即生效**，不用重启。
- **一套模板 = 一个子文件夹**，**文件夹名就是模板 id**，导出时按它找模板。
  所以别用 `/ \ ..` 这些字符，也**别改文件夹名**（改了等于换了一套模板，
  已经保存的快照里记的还是旧名字）。
- 放进去**不用重启**：模板是每次导出时现读的；导出弹窗里还有个「刷新」按钮。

## 自带的三套模板

| 模板 | 版式 | 适合 | 选中它时默认分组 |
|---|---|---|---|
| **默认讲义**（`模板/默认/`） | 11pt 单栏、每题留作答空白、标题居中 | 作业纸 | 平铺 |
| **紧凑题单**（`模板/紧凑题单/`） | 10pt 单栏、**不留白**、题目紧凑、标题左对齐加横线 | 复习清单 / 课堂速练 / 一页速览 | 按知识点 |
| **双栏试卷**（`模板/双栏试卷/`） | 9pt **两栏**、中间带分栏线、不留白 | 把整份卷子排成正式试卷，一页装更多题 | 按来源 |

三套模板在「设置 → 讲义模板」里**每页 3 个**列出来，显示名与描述都能就地改
（点名字旁边的铅笔修改，写回该模板自己的 `meta.json`）。

> ⚠️ **样式文件是每个模板自带一份的**：导出时按 `styleFiles` 原样复制进导出目录，
> 这样产物是自包含的、拷到别的电脑也能编译。所以如果你改了 `默认/quirex.sty`，
> 另外两套**不会跟着变** —— 想同步就手动复制过去。

## 一套模板的文件构成

```
模板/我的模板/
├── main.tex        讲义骨架（必填）
├── meta.json       模板的自我描述（必填）
└── quirex.sty      样式文件（名字自定，但必须写进 meta.json 的 styleFiles）
```

## 程序会给模板什么（接口）

导出时程序按这个顺序办事 —— 知道它，就知道模板该写成什么样：

1. **按 id 找目录并校验**：不可用就当场报错，不会"导到一半才炸"，也不会悄悄用坏模板编出一份错 PDF；
2. **组装题目正文**：把试题篮里每道题的 `题干.tex` **原样**拼成一大段（不做任何格式转换），
   整卷（`APxxx`，内容是 PDF）会被跳过并在界面上提示；
3. **替换占位符**：只替换 `tokens` 里**声明过的**那几个；`{{BODY}}` **最后**替换
   （否则题目里恰好写着 `{{TITLE}}` 这种字面文本会被误换）；
4. **复制样式文件**：把 `styleFiles` 列的每个文件原样复制进导出目录；
5. **写两份 `.tex`**：`题目.tex` 与 `答案.tex`，正文完全相同，只有开头的预设不同；
6. **跑 xelatex**：编译结果（成没成功、多久、有什么警告）回报到界面上。

导出目录长这样：

```
导出/期末复习/
├── 题目.pdf            只有题干 + 做题留白 —— 给学生做
├── 答案.pdf            题干 + 答案 —— 给老师 / 对答案
├── 题目.tex            生成上面两个 PDF 的源码
├── 答案.tex
├── quirex.sty          模板声明的样式文件（可能是别的名字）
├── images/             题目用到的图片（文件名带 qid 前缀，全局唯一）
├── build.bat           双击即编译（Windows）
├── build.sh            macOS / Linux
└── 编译说明.txt
```

#### `main.tex` 里可以写什么

它是一份**完整的 LaTeX 文档**，随便加宏包、随便排版
（「双栏试卷」就自己 `\usepackage{multicol}` 并包了一层 `multicols` 环境）。
唯一的要求是：**把 `meta.json` 里 `tokens` 声明的那几个占位符各写一次**，
导出时程序会把它们换成实际内容。

六个占位符：

| 占位符 | 会被换成 | 必须声明吗 |
|---|---|---|
| `{{TITLE}}` | 讲义标题（导出弹窗里那个，默认是时间） | 选填 |
| `{{AUTHOR}}` | 作者 | 选填 |
| `{{DATE}}` | 日期 | 选填 |
| `{{PRESET}}` | `\presetStudent` / `\presetAnswer` / `\presetTeacher` 之一 —— **题目版与答案版就是靠它区分** | **必须** |
| `{{LAYOUT}}` | `\normalLayout` 等留白版式宏 | 选填 |
| `{{BODY}}` | 题目正文（程序生成的，**最后一个替换**） | **必须** |

**用不到就别声明。** 「紧凑题单」与「双栏试卷」都没声明 `AUTHOR` 和 `LAYOUT`
（前者不需要作者行，后者把版式写死成 `\compactLayout`）。

> 题目正文里出现的宏（`\pick`、`\fillin`、`\fig`、`choices` 环境……）都由样式文件定义 ——
> 换一套模板时，`quirex.sty` 里那几个宏得照样有，否则题目的公式、括号、空线会渲染不出来。
> 想省事就直接复制现成模板的 `.sty` 再改。

#### `meta.json` 的字段

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| `schema` | ✅ | 数字 | —— | 契约版本，**必须是 `1`** |
| `name` | ✅ | 字符串 | —— | 导出弹窗里显示的名字（≤40 字）。可在设置页里改 |
| `styleFiles` | ✅ | 字符串数组 | —— | 要一并复制进导出目录的文件，**不能为空**；写了但文件不存在会报错 |
| `tokens` | ✅ | 字符串数组 | —— | `main.tex` 里用到的占位符，**必须含 `PRESET` 与 `BODY`** |
| `description` | 选填 | 字符串 | `""` | 一句话说明，显示在导出弹窗「模板」下面。可在设置页里改 |
| `engine` | 选填 | 字符串 | `"xelatex"` | 目前**只支持 `xelatex`**，写别的会被拦下 |
| `defaults` | 选填 | 对象 | `{}` | 只有一个键 `group`：选中这套模板时导出弹窗的「分组」默认切到 `flat` / `knowledge` / `source`（用户仍可随手改） |

#### 最小可抄的一份模板

`模板/我的模板/meta.json`：

```json
{
  "schema": 1,
  "name": "我的模板",
  "description": "一句话说明这套模板长什么样、适合什么场景。",
  "engine": "xelatex",
  "styleFiles": ["quirex.sty"],
  "tokens": ["TITLE", "PRESET", "BODY"],
  "defaults": { "group": "flat" }
}
```

`模板/我的模板/main.tex`：

```latex
\documentclass[11pt,a4paper]{book}
\usepackage{quirex}
{{PRESET}}
\begin{document}
\begin{center}{\LARGE\bfseries {{TITLE}}}\end{center}
\vspace{1em}
{{BODY}}
\end{document}
```

`quirex.sty` 直接复制现成模板里的那份（**每个模板目录各放一份**），
或者自己写一个 —— 只要文件名与前两处 `styleFiles` 对上。

> 上面这两段是**照抄就能用**的：`scripts/verify-v9-readme.ts` 会从**本文档**里
> 把它们原文抠出来，建成一套模板真导出、真编译一遍。
> 文档里的示例不会被验证的话，迟早会烂掉。

#### 校验规则（也是报错的依据）

放好文件夹**不用重启**（模板是每次导出时现读的）。设置页「讲义模板」会立刻列出它并给出结论，
下面任一条件不满足就是**不可用**、不能用于导出，并且会明确告诉你哪里错：

1. 目录里必须有 `main.tex`，否则报「缺少 main.tex」；
2. 目录里必须有 `meta.json`，且是**合法 JSON**，否则报错并给一份可照抄的骨架；
3. `schema` 必须等于 `1`；
4. `name` 不能为空；
5. `engine` 只能是 `xelatex`；
6. `styleFiles` 不能为空，且里面列的每个文件都要在模板目录里**真实存在**；
7. `tokens` 不能为空，且**不能出现不认识的占位符**（认识的只有上面那六个）；
8. `tokens` 里**必须含 `PRESET` 与 `BODY`**（少了 PRESET → 题目/答案两份会一模一样；
   少了 BODY → 没有正文）；
9. `tokens` 里声明的每一个，在 `main.tex` 里必须**恰好出现一次**
   （一次都没有、或写了两次，都会报出来）；
10. `main.tex` 里出现的占位符**都必须先在 `tokens` 里声明**。

第 9、10 条看的是**去掉注释之后**的 `main.tex` —— 所以注释里可以放心写
`{{BODY}}` 当文档说明，不会把正文注进注释里。

#### 常见错误对照表

| 症状 | 原因 | 怎么改 |
|---|---|---|
| 「缺少 main.tex」 | 只放了 `meta.json` | 补上 `main.tex` |
| 「缺少 meta.json」并给了一段 JSON | 忘了自我描述 | 把那段 JSON 存成 `meta.json` |
| 「schema 是 (没写)」 | 没写 `schema` | 加 `"schema": 1` |
| 「styleFiles 里写的 quirex.sty 找不到」 | 文件名与 `meta.json` 里对不上（比如实际叫 `mathatlas.sty`） | 改名或改 `styleFiles`，两边一致 |
| 「tokens 里缺少必须声明的 BODY」 | 忘了写正文位置 | 在 `main.tex` 里加上 `{{BODY}}` 并写进 `tokens` |
| 「tokens 声明了 TITLE，但 main.tex 里没有 `{{TITLE}}`」 | 声明了却没用到 | 要么写进 `main.tex`，要么从 `tokens` 里删掉 |
| 「`{{BODY}}` 出现了 2 次」 | 复制粘贴重复了 | 只留一处 |
| 「用了没在 tokens 里声明的占位符：AUTHOR」 | `main.tex` 里的占位符没登记 | 补进 `tokens` |
| 「engine 是「pdflatex」，目前只支持 xelatex」 | 写了别的引擎 | 改成 `xelatex` |
| 导出弹窗里选不到它 | 它被列成了「不可用」 | 去「设置 → 讲义模板」看那几条问题，按上面改 |

#### 改完想看效果

- **导出弹窗**里选它 → 直接导出，程序会把 `styleFiles` 一起复制进导出目录并真跑 xelatex；
- 「设置 → 讲义模板」里点这张卡的「打开文件夹」直接跳到模板目录；
- 想整体看一遍所有模板的合规情况，就到 `代码/` 里跑
  `npx tsx scripts/verify-templates.ts`（它顺便验证 15 类坏模板都被拦住了）。
